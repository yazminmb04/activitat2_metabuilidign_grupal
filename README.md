The Enchanted Room Game

Combination of the three activities into a single Mixed Reality (MR) application for Meta Quest.

Usage

This application allows users to interact with a Mixed Reality environment using Meta Quest devices. Users can visualize their physical surroundings through Passthrough, manipulate virtual objects (such as a cube or a sword) via hand tracking and controllers, navigate using teleportation and smooth rotation, scan their physical space, and spawn physics-enabled spheres that bounce off real-world surfaces.

Current features

● Passthrough & Environment Vision: Real-time Passthrough rendering with eye tracking, visual filters, masks, and real-world environment scanning.

● Grab & Distance Interaction: Grabbing, manipulating, and distance-selecting 3D objects (Cube and Sword) using both Touch controllers and Hand Tracking.

● Locomotion System: Teleportation arc system and smooth/snap turn interactions.

● Anchor Prefab Spawner: Dynamic spawning of physics-based spheres triggered via controller buttons.

● Room Mesh & Collisions (MRUK): Real-world mesh scanning and physical collision detection allowing spawned objects to bounce off real surfaces.

Installation

Download the latest .apk file from the repository's releases or build the Unity project targeting the Android/Meta Quest platform.

Install the APK on your Meta Quest headset (via SideQuest or ADB).

Open the app inside the headset and grant the required permissions (Camera / Spatial Data / Passthrough access).

History

This technical project was created for the Diseño, animación y arte digital program at Centro de la Imagen y la Tecnología Multimedia (CITM) - Universidad Politécnica de Cataluña (UPC).

The main goal was to explore and combine multiple Meta XR SDK features, MRUK (Mixed Reality Utility Kit), and Meta Building Blocks into a single cohesive scene inside Unity.
